# Issue Tracker

The Maid uses **GitHub Issues**.

## Repository

`https://github.com/imirkth/the-maid`

## Creating issues

Use `gh issue create --repo imirkth/the-maid --title "..." --body-file /tmp/issue.md`

See `docs/agents/triage-labels.md` for the label vocabulary.
